# RoboVision

## 分支介绍

### master

​	合入V4版本相机模块，最新版本为Deeplearning分支。

### V2

​	AForge分支，存在摄像头调用与深度学习不明确释放导致的内存泄漏及溢出问题

### V3

​	OpenCvsharp分支，解决了相机调用与深度学习调用的问题，相机模块可正常使用（正常选择并设置相机设备及对应的分辨率），通信模块待测试，深度学习模块基本框架。

### V4

​	V3分支的最终版本

### Deeplearning与Communication

深度学习模块。图像尺寸调整及绘制识别框，检测模型精度
通信模块。TCP 通信，接收图像数据，发送识别结果

### Final

系统整合与 UI
