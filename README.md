# RoboVision

RoboVision 是一个基于.NET Framework 的机器视觉系统，集成了摄像头控制、深度学习和网络通信功能，可用于实时物体检测和识别。

## 项目概述

RoboVision 系统主要包含以下功能模块：

- **相机模块**：支持多种分辨率的摄像头设备管理和图像采集
- **深度学习模块**：基于 ONNX Runtime 的实时目标检测与识别
- **通信模块**：使用 TCP/IP 协议进行实时数据传输和控制
- **用户界面**：直观的图形界面，方便操作和监控

## 系统架构

系统由以下核心组件构成：

1. **CameraController**：负责摄像头设备管理、参数设置和图像采集
2. **DeepLearningModel**：进行图像预处理、模型推理和结果后处理
3. **CommunicationModule**：负责网络通信和数据传输
4. **MainForm**：主界面和用户交互

## 使用指南

### 系统要求

- Windows 10 或更高版本
- .NET Framework 4.7.2 或更高版本
- 支持 DirectShow 的 USB 摄像头设备
- CUDA 支持（可选，用于 GPU 加速）

### 快速开始

1. 启动 RoboVision 应用程序
2. 点击"检测相机"按钮连接摄像头设备
3. 设置相机参数（分辨率等）
4. 点击"加载模型"按钮加载 ONNX 格式的深度学习模型
5. 点击"拍照"或"处理"按钮进行图像处理与识别
6. 检测结果将自动保存并可通过网络发送

### 性能建议

- 对于长时间运行的应用，推荐定期重启应用以释放资源
- 使用较低分辨率可以减轻系统负担，提高处理速度
- 尽量使用较新的 CUDA 版本获得更好的 GPU 加速效果
